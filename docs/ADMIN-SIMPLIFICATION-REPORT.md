# Admin simplification audit

5 October 2026. Implemented locally. No commit, push or deployment.

The existing Admin design and business workflows are retained. Normal editing now emphasizes images, readable choices, booking references and operational status. Image addresses, page addresses, coordinates and email troubleshooting details remain available where needed in closed disclosures.

## Implementation

- Website images keep desktop/mobile previews and Replace image. Removed filename, natural dimensions, crop dimensions and automatic-optimization notes. Original image values still submit through the same field names; manual address replacement remains in a single section-level Technical details disclosure.
- Destination, review and product images now use a shared presentation control with a preview, image replacement and optional removal. It reuses the existing image preparation/upload action, bucket and permissions. Raw-reference editing remains in Technical details. Saving is blocked while that form has an upload in progress.
- Image position labels are Center, Top, Bottom, Left and their corner combinations. Existing CSS values remain unchanged. Review languages show names while submitting existing language codes; custom codes remain available for support.
- Product and destination page addresses remain autogenerated and editable under Advanced. Coordinates move under Advanced: map position. Product/supplier names and existing publication options remain visible.
- Calendar wording uses maximum seats, usual schedule, date-range changes and prices for these dates. Range precedence, reservation warnings and age/seat rules remain explicit.
- Bookings use readable status labels and existing booking references. Product UUID fallback is hidden. Internal order ID and email attempts/error codes are restricted to Technical details. Refund, payment and cancellation safeguards remain intact.
- Email uses On/Off and readable message states. Provider/configuration information is moved to the existing Advanced disclosure. Sent explicitly does **not** mean confirmed inbox delivery. Notification preferences use In Admin / On this device.
- Unexpected action errors are logged server-side and receive a safe owner-facing fallback. Validation, concurrent-edit warnings and actionable image-size advice are preserved. No authentication, authorization or mutation condition was relaxed.
